# 前端规则

适用于 `src/` 下的所有代码。

## 职责边界

前端**只负责渲染和交互**。不持有 API Key，不直接发外部请求，不写业务规则。数据和外部调用一律通过 Tauri command 走 Rust 侧。

## 像素渲染（硬规则）

- 所有 sprite 元素必须设 `image-rendering: pixelated`，禁止任何平滑插值。
- **缩放只允许整数倍**（2x / 3x / 4x）。非整数倍缩放会让像素边缘出现毛刺，像素风立刻变廉价。
- 动画帧切换用整帧切换，不要用过渡动画在帧之间插值。
- sprite 规格（尺寸、帧率、状态机、优先级）见 `docs/PET-ASSETS.md`，改动规格要同步改那个文件。

## 依赖

**不引入 UI 组件库。** 桌宠界面高度定制，组件库带来的样式九成用不上，只会增加体积——而体积是这个产品的卖点（见 `docs/DECISIONS.md` D1）。

任何新依赖按 `CLAUDE.md` 的依赖引入规范提案。

## 常驻窗口的性能

宠物窗口 24 小时开着。空闲时（无动画、无交互）不应有持续的 JS 执行或重排。`idle` 动画用 `requestAnimationFrame` 并在窗口不可见时暂停。

## 透明窗口

窗口背景必须真正透明，不要给根元素设不透明背景色。命中测试区域（决定点击穿透开关）和视觉上的不透明区域要保持一致，否则会出现「看着能点却点不到」或「明明是空白却点不到桌面」。

## AI 交互

AI 返回的变更必须走预览确认 UI，**不存在跳过确认的快捷路径**。删除操作在预览里要最醒目。理由见 `docs/AI-PIPELINE.md`。

网络失败时**必须保留用户输入的原文**，不能让人重说一遍。
