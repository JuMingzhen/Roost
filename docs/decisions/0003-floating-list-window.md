# 0003：清单和气泡改用独立的圆角窗口

- 状态：提议
- 日期：2026-09-29
- 提出方：Claude Code
- 确认人：

## 背景

用户要求 M3 之前先做一次外观升级（效果图：https://claude.ai/artifact/DjJPGFQniYRPLjERBAXZar ）。清单和气泡要有平滑圆角和阴影。

M0 以来，宠物、清单、气泡都画在同一个窗口里。这个窗口用颜色键（品红）抠透明，再用窗口区域（Region）让宠物周围的空白可以点透（PRD 6.1）。颜色键只能做到"整像素要么透明要么不透明"，画不出抗锯齿的圆角：圆角边缘的半透明像素会混出品红毛边，不抗锯齿又是明显的锯齿。

## 候选方案

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| A（建议） | 清单和气泡各自放进一个无边框小窗口（宠物窗口的附属窗口），跟着宠物移动；用 Windows 11 的 `DWMWA_WINDOW_CORNER_PREFERENCE` 请求系统圆角 | 系统负责抗锯齿圆角、细边框和阴影；清单窗口是普通不透明窗口，里面可以自由自绘圆角控件；宠物窗口的点击区域只剩宠物本身 | 要同步三个窗口的位置、显示隐藏、透明度；Windows 10 没有系统圆角，退回直角（用户 2026-09-29 已接受） |
| B | 仍是一个窗口，用 `UpdateLayeredWindow` 按像素 alpha 整窗自绘 | 圆角和阴影完全自控 | WinForms 控件在这种窗口里不会自己绘制，输入框、按钮等全部要重写；改动量和风险都最大 |
| C | 仍是一个窗口，圆角用不抗锯齿的区域裁剪 | 改动最小 | 高缩放下锯齿明显，达不到效果图 |

## 实测数据

- 环境：用户的开发机，Windows 11（10.0.26200），单显示器，真实 200% 缩放。
- 方法：
  - `Roost.Verify system`：清单窗口可见、整体透明度 85%（分层窗口，最难的情况）。截取清单窗口四个角的屏幕像素，应露出下层测试窗口的颜色。同时照常检查 12 个空白点的点击穿透、快捷键隐藏、全屏隐藏、托盘和设置入口。
  - `verify-layout.ps1`、`verify-ai.ps1`、`verify-pixel.ps1`、`verify-resource.ps1` 全部重跑。
  - 这一步只把清单和气泡搬进独立窗口，外观保持不变，方便和 M2 收尾时的数据对比。
- 结果：
  - 圆角：系统接受圆角设置。两次运行四个角的像素分别为 `#00007D` / `#00007D` / `#000073` / `#000073` 和 `#070780` / `#070780` / `#060675` / `#030372`，下层测试窗口为 `#000080`，差值来自系统阴影；清单底色 `#FAF6EF` 没有出现。检查按每个通道 ±24 的容差比较，截图见 `artifacts/m1/system.corner.png`。
  - 点击穿透：12/12 空白点击落到下层窗口；点宠物仍能折叠清单。
  - 快捷键隐藏时清单窗口一起隐藏；全屏隐藏与恢复、单实例唤回均通过。
  - 排版：9 个界面 0 问题。AI 流程 15 项全部通过。像素检查通过（真实窗体截图与模拟布局均无异常像素）。
  - 资源（10 分钟，`verify-resource.ps1`）：

    | | M2 收尾（单窗口） | 拆成三个窗口 |
    |---|---|---|
    | 平均 CPU | 0.214% | 0.2337% |
    | 平均 / 峰值内存 | 54.16 / 54.89 MB | 56.98 / 57.98 MB |
    | 可见时帧数 | 4,794 | 4,799 |
    | 隐藏 30 秒帧数 | 0 | 0 |

    多了两个窗口，内存约增加 3 MB，CPU 基本不变，都在 PRD 第 13 节范围内。
  - 测量方法修正：第一次跑资源测试时，隐藏期间帧数是 -4801。原因是测试读的帧计数会在宠物切换状态时归零（窗口隐藏时触发了"鼠标离开"，悬停切回待机），而不是动画在跑。已改成读只增不减的定时器触发次数（`SpriteView.FrameCount`），这正是"隐藏时动画暂停"要检查的量。改后重跑为 0。

## 结论

采用方案 A。

## 影响

- PRD 指标：见上面的资源数据。没有新增依赖，只多调用了一个系统接口（dwmapi）。
- 对后续开发的约束：
  - 宠物窗口的点击区域只包含宠物。清单和气泡是宠物窗口的附属窗口，随宠物窗口显示和隐藏（`PetForm.PlaceFloating`）。
  - 判断"前台是不是全屏窗口"时，要把这两个附属窗口也当成 Roost 自己。
  - 「跟宠物说」快捷键要把焦点给清单窗口。
- PRD：不需要修改。
