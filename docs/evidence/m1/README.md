# M1 自动验证证据

生成日期：2026-09-21。

- `system.json`：生产窗体的空白点击穿透、宠物命中、托盘项、全局快捷键、隐藏暂停、全屏隐藏与恢复。
- `single-instance.json`：第二进程退出并通知首实例显示。
- `pixel.json`：6 个产品状态、3 档尺寸、100% / 125% / 150% 模拟缩放布局，共 54 个颜色集合检查。
- `pixel-screenshots/`：上述 54 个全分辨率 PNG。
- `resource.json`：生产窗体连续动画 10 分钟及隐藏 30 秒的 CPU、内存和帧计数。

复现命令见仓库根目录 `AGENTS.md`。像素测试使用生产渲染路径，但自动脚本不会修改 Windows 显示设置；真实 100% / 125% / 150% 缩放仍按 `docs/PROGRESS.md` 手动复测。
