# M1 自动验证证据

生成日期：2026-09-21；真实 DPI 门禁补充于 2026-09-22。

- `system.json`：生产窗体的空白点击穿透、宠物命中、托盘项、全局快捷键、隐藏暂停、全屏隐藏与恢复。
- `single-instance.json`：第二进程退出并通知首实例显示。
- `pixel.json`：6 个产品状态、3 档尺寸、100% / 125% / 150% 模拟缩放布局的 54 个检查，以及当前真实 200% Windows 缩放下的 18 个窗体截图检查。
- `pixel-screenshots/`：上述 72 个全分辨率 PNG。
- `resource.json`：生产窗体连续动画 10 分钟及隐藏 30 秒的 CPU、内存和帧计数。
- `dpi-100/`、`dpi-125/`、`dpi-150/`：三档真实 Windows 缩放门禁的 `system.json`、`pixel.json`，以及每档 18 张生产窗体全分辨率截图。三档均检测到预期实际缩放，空白点击均为 12/12，真实截图与模拟布局均无异常颜色像素，`overallPass` 均为 `true`。

复现命令见仓库根目录 `AGENTS.md`。像素测试使用生产渲染路径并记录验证进程实际检测到的 DPI；脚本不会修改 Windows 显示设置，因此复测时仍需先手动切换到目标缩放。
