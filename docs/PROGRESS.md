### 真实 DPI 复测（M1 合并前门禁）

1. 保存工作并关闭其他会遮挡测试区域的置顶窗口；在 Windows 设置中把单显示器缩放设为 100%，注销/重启按系统提示执行。
2. 在仓库根目录运行 `.\verify-system.ps1` 和 `.\verify-pixel.ps1`。预期系统 JSON 为 `PASS`，像素 54/54、异常像素 0；肉眼确认宠物和清单边缘锐利。
3. 将缩放改为 125%，运行 `.\verify-pixel.ps1` 并做同样检查。
4. 将缩放改为 150%，运行 `.\verify-system.ps1` 和 `.\verify-pixel.ps1` 并做同样检查。
5. 把三档的 `artifacts\m1\system.json` / `pixel.json` 分别另存并回传结果。自动脚本不会修改系统缩放，也不会把模拟布局冒充真实覆盖。

### 首次启动与日常交互目视检查

1. 指定一个新的空数据目录运行 `dist\Roost.exe`；预期出现空清单引导，明确说明「+」、点击宠物折叠、AI 与自启设置入口，且不强制配置模型。
2. 通过表单新建、编辑、星标、完成后取消、删除后撤销一条虚构待办；预期 UI 与自动测试中的状态变化一致，完成时播放庆祝状态。
